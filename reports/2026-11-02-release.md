# 保存と再利用を中心にした公開改修

本人から改修・PRマージ・公開まで委任（2026-11-02）。Craftbase TOPと同時に公開する。

## 内容

- 全幅の日本語LP、登録なしの`/notes`、アカウント登録とログインの区別。
- 既存の端末内保存・クラウド同期を維持。保存後は`/notes`へ戻る。
- 公式テンプレートを実績と区別し、安定ID、本文からの非公開複製、コピー結果確認。
- 固定AI見本は見本と明示し適用しない。自前キー以外のAI実行は認証と月10回上限をGroq/Anthropicで共通化。
- PC/スマホの主要導線・ノートの文字・詳細モーダル・編集バーを整える。
- Next.js 16.4.3へ更新し、`npm audit --omit=dev`は0件。原価・決済金額・DBスキーマは変更しない。
- ESLint設定とhooksプラグインは元lockの16.1.7/7.0.1を固定し、公開改修とルール全移行を分離。

## Claude途中レビューへの対応

- P1 公開本文が認証待ちで隠れる：公開LPと共有ページは先に描画、実AppShellのSSR回帰でRED→GREEN。
- P2 使い方の全幅表示：自前の最大幅を付与。
- P2 ゲストAI説明の不整合：説明とサーバー認証ガードを修正、17回帰で確認。
- P2 スワイプコピー：最新実装で成功/失敗を待つhelperへ統一済み。
- P2 Craftbase共有画像：別repoで1200×630の専用画像を作成。
- 最終レビュー P2 ゲストの未実在公開URL：端末内保存は非公開に限定し、サーバー保存済みの公開指示だけ共有するガードを追加。2回帰でRED→GREEN。
- 旧sampleが自分のノートに残るという懸念：store.getDocumentsはuserId=sampleを除外しており非該当。旧利用者の保存データは削除しない。

## 検証

`npm test`、`npx tsc --noEmit`、`npm run lint`、`npm run build`を使用。テストのNode標準TS実行とregisterHooksにはNode 22.15以降が必要（作業端末はNode 25.6.1）。lintに残る既存の未使用変数・img推奨の警告はエラーと区別する。

ブラウザではローカルの隔離コンテキストを使用し、架空ノートの作成→保存→一覧→再読込、公式テンプレート詳細→コピー→自分用に保存を検証。メール送信、実課金、顧客データの操作は行わない。公開後結果はCraftbase側の公開記録に追記する。
